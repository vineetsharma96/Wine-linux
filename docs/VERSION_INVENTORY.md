# Software and asset version inventory

Initial review dated 2026-11-25. Versions in the candidate column need a build and ARM64 device check before adoption. An unchecked security status means the component has not passed a dedicated advisory review.

Stage 3.2 adds no linked third-party dependency. It reuses Android's public ANativeWindow/Surface APIs (app minimum 26, linked with NDK 30.0.16248370), the in-tree Rust RFB engine (Apache-2.0 OR MIT), and the inventory's guest TigerVNC 1.15.0 and XFCE 4.20 packages. The external reference used the installed Termux 0.118.3 and Termux:X11 1.03.01-d55f1b7-28.09.26 APK, with GPL-3.0 source reviewed at `24ce2076`. The pre-existing BSD-3-Clause libandroid-shmem binary matched the verified Termux 0.7 ARM64 package. It is outside the renderer. [Android Native Window](https://developer.android.com/ndk/reference/group/a-native-window) · [Lorie source and license](https://github.com/termux/termux-x11/tree/24ce2076fe68eff1599da286c5c162f7693c0501) · [libandroid-shmem 0.7](https://github.com/termux/libandroid-shmem/tree/v0.7)

Stage 3.1 retains the locked Rust dependencies, ARM64 Ubuntu Base 26.04.1 and Debian 13.8 artifacts, NDK r30, PRoot build, TigerVNC, and XFCE already used by the app. It uses the existing guest `dbus-run-session` and `xfce4-session-logout` executables. Canonical's archive mapping and the existing Android trust source were reviewed for the HTTPS Ports transition. [Canonical archive mapping](https://documentation.ubuntu.com/chisel/en/latest/reference/chisel-releases/) · [Android trust store](https://source.android.com/docs/core/ota/modular-system/conscrypt) · [D-Bus session documentation](https://dbus.freedesktop.org/doc/dbus-run-session.1.html)
