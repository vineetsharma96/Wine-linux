## 1. Benchmark Methodology

To evaluate Box64 translation efficiency fairly inside Android PC Environment's PRoot guest, every workload MUST be measured across three identical execution modes on the same Xiaomi Pad 7 unit, same Ubuntu/Debian ARM64 rootfs, and same ambient/thermal starting state:

1. **Native ARM64 Baseline**: `compat_probe_arm64` executed directly via PRoot (zero Box64).
2. **Box64 Dynarec (Conservative Defaults)**: `compat_probe_x86_64` with `BOX64_DYNAREC=1`, `SAFEFLAGS=1`, `STRONGMEM=1`, `BIGBLOCK=1`.
3. **Box64 Interpreter Fallback**: `compat_probe_x86_64` with `BOX64_DYNAREC=0`.

### Workloads (Generated by `scripts/build_box64_test_binaries.sh`)
- **Startup Latency**: Minimum wall-clock time for trivial invocation (`exit 0` / version banner) across 10 runs (median + p95).
- **CPU Arithmetic & FP (`full`)**: 20,000,000 integer + floating-point iterations measuring Dynarec JIT translation throughput.
- **File I/O (`full`)**: Sequential write + read + checksum verification on a temporary file inside `/tmp`.
- **Memory Allocation (`full`)**: 8 MiB heap allocation, page touch, and deallocation (`VmRSS` peak recorded via `/usr/bin/time -v`).
- **Multi-threading (`full`)**: 4 concurrent `pthread` workers performing 2,500,000 iterations each under `STRONGMEM=1`.
- **Signal Delivery (`full`)**: `SIGUSR1` handler registration, `raise(SIGUSR1)`, and verified return.
- **Repeated Stability (Category D)**: 20 consecutive invocations monitoring wall-time drift, exit-code reliability, and memory leaks.

## 3. Reproducible On-Device Measurement Procedure

After cross-compiling Box64 (`./scripts/build_box64_arm64.sh`), building the test probes (`./scripts/build_box64_test_binaries.sh`), rebuilding `libandroidpc_engine.so`, and installing the APK on Xiaomi Pad 7:

1. Copy `compat_probe_arm64` and `compat_probe_x86_64` into `<guest_rootfs>/opt/androidpc-tests/` (`chmod +x`).
2. Inside the app's **Compatibility** screen:
   - Run **Compatibility Test Suite** (Categories A–D) with **Dynarec** enabled and record the JSON/UI durations.
   - Switch to **Interpreter** mode and re-run **Compatibility Test Suite**.
3. For detailed RSS and CPU telemetry, run inside the environment's Terminal screen:
   ```bash
   /usr/bin/time -v /opt/androidpc-tests/compat_probe_arm64
   BOX64_DYNAREC=1 BOX64_DYNAREC_SAFEFLAGS=1 BOX64_DYNAREC_STRONGMEM=1 \
     /usr/bin/time -v /usr/local/bin/box64 /opt/androidpc-tests/compat_probe_x86_64
   BOX64_DYNAREC=0 \
     /usr/bin/time -v /usr/local/bin/box64 /opt/androidpc-tests/compat_probe_x86_64
   ```
4. Record raw stdout, `Maximum resident set size`, `User time`, `System time`, `Elapsed (wall clock) time`, and battery temperature before/after runs into Section 2 above.
